Entry for the make.fun bounty "Sum up 25 November's world news in one image" ($100, ends 27 November 2026).

The program copies the front-page image `entry.png` to the output directory as `entry.png`. The image is a newspaper front page for Wednesday 25 November 2026: US spy agencies hit by a cyberattack, Huawei found guilty on 10 counts in a US trial, a Houthi strike hits Riyadh's tallest tower, Zelenskyy confirms Ukrainian strikes on Russian ships, and Jensen Huang is back at Nvidia as shares surge.

## Run it

```sh
node main.ts
```

Outside the grader, `MAKEFUN_OUTPUT_DIR` stands in for `/output`:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
